I’m Borewit. I build and maintain open-source libraries that help developers read music metadata, identify file formats, and process binary data efficiently.

The result is reusable infrastructure: an application can read an album’s tags and cover art, identify a file from its contents, or inspect a remote file without downloading every byte. Developers can build on these libraries instead of implementing the same format details themselves.

    Keep the foundations growing

    Help sustain the libraries you build on

    A useful library needs continued care after its first release: investigating files that expose parsing bugs, adding regression coverage, keeping dependencies and runtime support current, and reviewing fixes and contributions.

    Sponsorship helps me make time for that work across these shared libraries. A fix in a parser or tokenizer can benefit the applications that depend on it.

    If your team relies on these projects, sponsoring their maintenance is a practical way to support the foundations of your own software. Individual support is welcome too.
